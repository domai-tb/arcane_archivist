# Arcane Archivist Living Spec

This folder contains the versioned living specification for Arcane Archivist.

## Canonical Version Ladder

- [0.1](./0.1.md): first playable slice
- [0.2](./0.2.md): archive combinations and basic persistence
- [0.3](./0.3.md): deck refinement and early synergy depth
- [0.4](./0.4.md): patron requests and research loop
- [0.5](./0.5.md): integrated library-dive-archive loop
- [0.6](./0.6.md): progression depth, curses, and replayability
- [0.7](./0.7.md): content-complete core loops
- [0.8](./0.8.md): polish and balance
- [0.9](./0.9.md): platform readiness and production hardening
- [1.0](./1.0.md): full release feature set

## Reading Order

Start with `0.1` and read upward. Each version assumes the prior version is complete and then adds a bounded scope of new systems, content, or quality requirements.

## Scope Rule

Modding, plugins, and other player-extensible systems are not part of the `1.0` release spec. They remain future-facing unless explicitly added in a later post-`1.0` version.
